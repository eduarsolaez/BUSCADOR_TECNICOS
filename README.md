# Buscador de Transformadores - ISES S.A.S

Esta es una aplicación web diseñada para técnicos en campo, que permite la búsqueda y visualización de transformadores y sus clientes asociados.

## Características
- **Búsqueda Multicriterio**: CT, Matrícula de Transformador, Medidor, NIC, etc.
- **Soporte de Bancos**: Identificación visual de múltiples transformadores compartiendo una misma ubicación (CT).
- **Mapa Interactivo**: Visualización de equipos cercanos (radio de 300m) utilizando Leaflet.js.
- **Optimizado para Móviles**: Interfaz ligera y rápida para consulta en tiempo real.

## Estructura
La aplicación funciona como un sitio estático alojado en **GitHub Pages**. Todos los datos se consultan vía JSON desde la carpeta `docs/api/`.
